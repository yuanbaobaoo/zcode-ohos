# 07 系统栏主题跟随（深浅色）

鸿蒙 PC 的系统栏（顶部状态栏 + 底部 Dock/任务栏）颜色由桌面进程（sceneboard）渲染，
应用可控维度只有**深/浅/跟随系统三态**（`ApplicationContext.setColorMode`），不能自定义
任意颜色（`setWindowSystemBarProperties` 的颜色字段在 PC 形态调用成功但视觉无效）。

## 行为定义

- 启动时按**应用主题设置**（设置 → 外观）声明系统栏深浅：深色主题 → 深色系统栏，
  浅色 → 浅色，跟随系统 → 不声明（保持系统默认）。
- 运行期主题切换**不生效**（setColorMode 一旦设置不可再改，真机实证）——重启后跟随新主题。
- 与窗口最大化/还原无关：声明后系统栏颜色恒定（这是 setColorMode 的应用级语义，DevEco
  Studio 的效果同源）。

## 实现链路（真机实证，HAD-W32 / HarmonyOS 7）

```
renderer 主题（useDesktopNativeThemeSync）→ IPC SetTitleBarTheme
  → main: nativeTheme.themeSource（在 libelectron.so 内空转，不触达 ArkTS，埋点实证）
  → main（本特性新增）: 写沙箱桥文件 /data/storage/el2/base/haps/electron/files/window-theme.json
       ↓ 同一文件（share-inbox 先例的沙箱双视图：Node 扁平路径 = ArkTS context.filesDir）
ArkTS EntryAbility.onCreate（窗口创建前，早于主窗渲染）
  → 读 context.filesDir/window-theme.json
  → setColorMode(DARK / LIGHT / NOT_SET)
  → WMS 按会话 colorMode 渲染系统栏（GetCallerSessionColorMode 实证）
```

启动时 main 先写 `system` 占位，主题就绪后由 IPC 链覆盖为真实主题（首窗晚于 renderer
就绪，时序成立）。

### 平台事实（真机实证）

| 事实                                          | 证据                                                                         |
| --------------------------------------------- | ---------------------------------------------------------------------------- |
| 系统栏颜色 = 应用 colorMode 三态              | WMS 日志 `GetCallerSessionColorMode`；PoC setColorMode(0) 使 Dock 由浅转深   |
| setColorMode 设置后不可再改                   | 运行期改 LIGHT/NOT_SET 无效，重启进程后才按新声明生效                        |
| `setWindowSystemBarProperties` 颜色不生效     | 状态栏设红/导航栏设蓝，API resolve 成功但像素无变化                          |
| `nativeTheme.themeSource` setter 不触达 ArkTS | main 设 dark 后 ArkTS `setSystemNativeTheme/setAppColorMode` 埋点零输出      |
| 沙箱双视图                                    | Node `/data/storage/el2/base/haps/electron/files` = ArkTS `context.filesDir` |

## 文件桥格式

- 路径：`haps/electron/files/window-theme.json`，内容 `{"theme":"dark"|"light"|"system"}`。
- 写方唯一：main 的 `SetTitleBarTheme` handler + 启动兜底（`desktopOhosWindowTheme.ts`）。
- 读方唯一：ArkTS `EntryAbility.onCreate`（`applyWindowThemeFromBridge`）。
- 文件缺失/损坏 → 视为 system（不声明）。

## 验收场景（已实测）

1. 深色主题 + 重启 → Dock/状态栏深 rgb(67,73,73)（与 DevEco Studio 一致）✓
2. 浅色主题 + 重启 → 系统栏回浅 rgb(207,213,212) ✓
3. 运行期切换主题 → 当前进程不变，重启后生效（平台限制）✓
4. 文件缺失/损坏 → 跟随系统，无异常 ✓（bridge 读取 catch 降级）
